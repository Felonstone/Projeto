LAR & CIA — LOJA VIRTUAL DEMONSTRATIVA

COMO ABRIR
1. Extraia a pasta Site para o seu computador.
2. Abra Site/pages/index.html no navegador.
3. Para uma experiência melhor, use a extensão Live Server no VS Code.

ARQUIVOS PRINCIPAIS
- pages/index.html: página inicial.
- pages/produtos.html: catálogo, filtros e pesquisa.
- pages/produto.html: detalhes do produto (recebe ?id=organizador, ?id=vaso etc.).
- pages/carrinho.html: carrinho salvo no localStorage do navegador.
- pages/checkout.html: formulário ilustrativo de checkout.
- pages/login.html, cadastro.html e pedidos.html: páginas de conta demonstrativas.
- css/style.css: identidade visual responsiva em vermelho e branco.
- js/main.js: catálogo de demonstração, pesquisa, filtros e carrinho.

IMPORTANTE
Este projeto é somente front-end. Os produtos, preços, avaliações, frete e promoções são exemplos. O checkout não processa pagamentos e não cria pedidos reais. Login, cadastro e histórico de pedidos não estão ligados a um servidor ou banco de dados. Antes de publicar, conecte um back-end seguro, estoque real, políticas de entrega/devolução e um provedor de pagamentos confiável. As imagens são carregadas de URLs externas do Unsplash e exigem conexão com a internet.
